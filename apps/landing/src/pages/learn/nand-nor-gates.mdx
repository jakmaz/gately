NAND and NOR invert the output of AND and OR. Each is also a universal gate: combinations of NAND gates, or combinations of NOR gates, can express any Boolean function.

## NAND gate

NAND outputs `0` only when both inputs are `1`. For every other input combination, its output is `1`.

Turn both switches on, then turn either one off.

## NOR gate

NOR outputs `1` only when both inputs are `0`. Turning on either input makes the output `0`.

Compare this with OR: every output value is inverted.

## Read the symbol

The small circle at a gate's output represents inversion. An AND shape with this circle is NAND; an OR shape with the circle is NOR.
