## Local circuit files

Gately saves changes to the current circuit in browser storage. Use the file panel to switch between circuits and organize them in folders.

Local storage belongs to that browser on that device. Clearing site data can remove saved work, so export circuits you want to keep.

## Export a circuit

1. Open the circuit you want to save.
2. Choose **Export Circuit** in the header.
3. Keep the downloaded `.json` file as a backup.

The file contains the circuit's nodes, positions, connections, and data.

## Import a circuit

1. Choose **Import Circuit** in the header.
2. Select a circuit JSON file exported from Gately.
3. The imported circuit opens as a new local file.

Importing does not replace the circuit you were working on.

## Move or share your work

Send the exported JSON file to someone else, or import it on another device. Public circuit links and account-based synchronization are not available.
