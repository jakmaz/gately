## Select an input

A two-to-one multiplexer has two data inputs, one selector, and one output.

- When **Selector** is `0`, the output follows **Channel 0**.
- When **Selector** is `1`, the output follows **Channel 1**.

## Try the circuit

Set Channel 0 to `1` and Channel 1 to `0`. Change Selector and watch which channel reaches the output.

## Build it from gates

NOT inverts the selector. One AND gate combines Channel 0 with the inverted selector; the other combines Channel 1 with the selector. OR combines the two paths into one output.

The output is `(Channel 0 AND NOT Selector) OR (Channel 1 AND Selector)`.

The editor also includes a **MUX** component. Building the function from basic gates helps explain what that component does.
