## What you'll build

This circuit has two input switches, an AND gate, and an output. The output is `1` only when both inputs are `1`.

Try each switch on its own, then turn both on.

The example uses gray for `0` and blue for `1`. To build your own version, [open the editor](https://app.gately.dev) and choose or create a circuit in the file panel.

## 1. Add two switches

Find **Toggle Switch** under **Input & Output** in the **Components** panel. Drag two switches onto the canvas, one above the other.

The upper switch will be input A; the lower one will be input B.

## 2. Place an AND gate

Find **AND** under **Basic Logic Gates**. Place it to the right of the two switches, with space for the connections.

## 3. Connect the inputs

Drag from the upper switch's output handle to one input handle on the AND gate. Connect the lower switch to the other input handle.

Each switch should feed a different gate input.

## 4. Add an output

Drag **Output** from **Input & Output** to the right of the gate. Connect the AND gate's output handle to it.

## Check the result

Turn on one switch. The output stays `0`. Turn on the second switch and the output becomes `1`. Turning either switch off returns it to `0`.

The circuit updates as you change inputs. Next, compare this behavior with [other basic gates](/learn/basic-gates).
